4 ноября 2026 года. Цель выпуска: https://radius-company1.github.io/radius/lexicom/ . Основной домен и DNS не переключаются.

Состав: все подготовленные доработки мобильной версии и интерфейса из [отчёта](../../release-readiness-2026-11-04.md), исходники обработчика заявок с [инструкцией специалисту](../../contact-form-handoff.md), документация/SEO и фактура Lexicom.

Дополнительно:

- Значок вкладки заменён на жёлтый микрофон из `projects/belarusbank-speech-analytics/assets/favicon.svg`. Ссылка на favicon имеет новую версию для обновления кеша браузера.
- В меню направлений возвращён первый пункт «Главная», с отметкой активной страницы и закрытием мобильного списка после перехода.
- README приведён к действующему источнику и способу публикации. Конфигурация проверки React перенесена из клона публикации в единственный источник.

До push выполнены сборки launch и Pages; `verify:launch` проверил 17 страниц, перенаправления и 404. В браузере проверены главная, МФЦ и ИИ-агент на ширинах 320, 390, 768, 1024 и 1440 px: переход домой, активный пункт, закрытие меню, загрузка нужного SVG, отсутствие переполнения и ошибок JavaScript. Снимки меню просмотрены.

С дополнительными правилами React проверка кода завершается без ошибок, но сообщает 17 предупреждений в существующих компонентах (эффекты, refs, быстрый перезапуск разработки). Ранее зафиксированная проверка без этих правил была чистой; это различие конфигураций, а не новая ошибка сборки. Размер общего JS также остаётся предупреждением Vite.

Обработчик почты на GitHub Pages не запускается. В опубликованной сборке VITE_CONTACT_ENDPOINT не задан: email/телефон работают как прямые контакты. Установка сервера и приёмка письма — следующий шаг специалиста.

Предыдущие отчёты сохранены как снимки состояния на момент проверки. Состав этого выпуска описан здесь. Окончательное подтверждение публикации — успешная сборка GitHub Pages и сравнение публичных HTML/SVG/JS/CSS с деревом релиза.
