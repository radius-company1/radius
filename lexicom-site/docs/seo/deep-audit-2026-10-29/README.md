# Углублённый аудит Lexicom — 29.10.2026

Предыдущий SEO-пакет был подготовкой семантики и метаданных. Он не давал оснований считать сайт готовым к запуску или прогнозировать результат продвижения. Этот аудит проверяет дополнительные риски, включая ошибки в самой предыдущей реализации.

## Что проверено

Три среды разделены: действующий lexicom.ai, опубликованная GitHub Pages-копия и текущая локальная сборка. У последней уже **14 индексируемых страниц**, включая новую /company/. Её реквизиты, новый email и цену добавили до этого аудита: данные сохранены, происхождение не приписывается SEO-работе.

Проверены публичные HTTP-ответы, WWW/TLS, robots/sitemap, исходный HTML; 14 локальных страниц, ссылки/якоря/ID/изображения; мобильное отображение, сбой JS, работа без JS, сохранение HTML при старте приложения, модальные окна, canonical; Lighthouse и axe. Дополнительно выполнены 12 отдельных поисковых запросов для проверки намерений.

## Воспроизведённые проблемы и изменения

| Проблема | Статус |
|---|---|
| Пререндер удалялся при createRoot и строился заново | Исправлено локально: hydrateRoot сохраняет готовый DOM; проверена идентичность H1 до/после загрузки |
| При заблокированной загрузке JS все reveal скрыты, в т.ч. H1 продукта/компании | Исправлено: по умолчанию текст виден, скрытие включается только работающим наблюдателем для блоков ниже экрана |
| Без JS форма отправляла поля GET-запросом в URL | Исправлено: POST, отключённые поля/кнопка до готовности клиента; контактный способ связи без JS. Backend этим не подключён |
| Список внедрения ol → div → li | Исправлена структура ol → li; сохранены анимация и оформление |
| Названия кнопок для скринридера не включали видимый текст | Исправлены названия увеличения изображения и видео |
| Два элемента id=contact на главной | Форма теперь contact-form; якорь секции contact сохранён |
| Preview одновременно Disallow / и noindex | Исправлено: обход разрешён, HTML содержит noindex, sitemap пуст |
| Проверка была жёстко привязана к 13 страницам | Список ожидаемых URL берётся из реестра страниц; сейчас проверены 14 |

INP реальных посетителей не измерен.

## Что остаётся до качественного запуска

1. Действующий www.lexicom.ai: сертификат не соответствует имени хоста. Подтверждено urllib и curl. Нужен администратор HTTPS; код лендинга это не исправляет.
2. На живом lexicom.ai robots/sitemap по-прежнему ссылаются на localhost. Публичная Pages-копия не содержит noindex в исходном HTML. Новые исправления не опубликованы.
3. Форма не доставляет заявки; три юридические ссылки остаются заглушками. Реквизиты теперь ведут на /company/ — прежнее утверждение о четырёх заглушках уже устарело.
4. Пользователь подтвердил: Метрика, Вебмастер и Search Console не подключены. Нет исходных данных по показам, запросам и конверсии.
5. Ядро из 268 фраз остаётся набором кандидатов. Изучение намерений улучшено; частотности и локализованные позиции не получены.
6. Нужны подтверждения публичных цифр/кейсов, точная ссылка на карточку реестра, согласование контактов/коммерческих условий и контроль переноса старых URL.
7. Остаётся тяжёлый общий JS/CSS. Следующая оптимизация — разделение кода и стилей по маршрутам после измерений, с отдельной регрессией интерфейса.

Не созданы вымышленные счётчики, события успешных заявок, цены, отзывы и новые юридические тексты. DNS, сертификаты, сервер и опубликованные версии не менялись.
