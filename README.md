# Безопасный регион Тульской области — РАДИУС

Персональный лендинг-презентация: развитие инфраструктурного слоя региональной системы видеонаблюдения и видеоаналитики Тульской области.

## Зона ответственности

РАДИУС отвечает за инфраструктуру **от коммутатора, который принимает видеопоток (включая сам коммутатор),
до вычислений и хранения**. Прикладное ПО, видеоаналитика и **АРМ оператора — вне зоны** (аппаратная/системная
часть АРМ может входить в проект; специализированное ПО — у вендора). Конечный сервис — для
**государственных ведомств**. Конкретный вендор ПО для Тулы на лендинге не называется.

**В зоне:** коммутаторы · СКЗИ на каналах · серверы и GPU под видеоаналитику · российская виртуализация ·
СХД · видеоархив как ёмкость · ИБП и охлаждение · мониторинг · CMDB · IPAM/DCIM · логи ·
ITSM и координация смежных подрядчиков · изолированные среды без интернета.

**Вне зоны:** сами камеры и их монтаж, прикладное ПО видеоплатформы и аналитики, разработка алгоритмов ИИ,
рабочие места операторов (АРМ), регламенты работы государственных ведомств.

Граница на странице:

| Где | Как показано |
|-----|--------------|
| Схема в hero | Красная рамка `ЗОНА РАДИУС` вокруг коммутации → СХД/архив; камеры сверху, АРМ и служба внизу вне рамки, вендор ПО справа |
| `#contour` | `.contour-flow`: шаги в зоне и `--out` вне зоны + сквозные сервисы эксплуатации |
| `#ops` / `#role` | Жизненный цикл и границы ответственности |
| `#security` | Контур ИБ инфраструктуры |

Не возвращать АРМ в зону РАДИУС без явной просьбы.

## Публичные ограничения копирайта

- Не называть ЦРТ, МВД и ФСБ: «вендоры прикладных решений» и «государственные ведомства».
- SLA в `#why` — рабочая практика РАДИУС, не утверждённый контракт по Туле.
- Цифры кейсов (Курск и др.) — факты практики, не обобщение на Тулу.
- Astra Linux / ViPNet — опыт регионов, не выбранный стек для Тулы.
- На дашбордах: без адресной строки и без имён ведомств; цифры с экрана не выдавать за Тулу.
- Чертежи `#drawings`: `scheme-cabinets.jpg`, `scheme-racks-rear.jpg`; цифры со штампа не переносить в блок текущего состояния.

## Драматургия

Навигация: **Задача / Модель / Практика / Эксплуатация / Как начать / Контакты**.

Порядок: задача и масштаб → целевая модель → чертежи → контур → цепочки отказов →
**практика** (Воронеж / Белгород / Курск целиком) → жизненный цикл → наблюдаемость → ИБ →
почему РАДИУС → результат → как начать → CTA → контакты.

Секция `#practice`: три полноценные главы, без вкладок. Без блока «100–300 камер» и без `#action`
с аналитикой вендора.

Слово «контур» — за hero, `#contour` и связанными формулировками; в остальных местах —
«периметр», «сегменты», «среда», «состав».
