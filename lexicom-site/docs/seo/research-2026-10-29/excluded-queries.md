# Отсев нерелевантных запросов

Это правила SEO-отбора, не готовый универсальный список минус-слов Директа. В рекламе нельзя механически запрещать «врач» и «МФЦ» во всех группах.

| Группа | Примеры | Решение |
|---|---|---|
| Услуги гражданам | записаться к врачу 122; вызвать врача; телефон МФЦ; статус заявления; соцзащита телефон; когда выплатят пособие; передать показания; отключили воду куда звонить | Не целевые покупатели ПО; использовать B2B/B2G-уточнения |
| Работа | оператор колл центра вакансии; удаленная работа оператором; зарплата оператора; вакансии Lexicom | Отдельный HR-поток; сохранить старые вакансии при миграции |
| Аутсорсинг | услуги операторов; аренда операторов; обзвон живыми операторами | Не обещать без подтверждения услуги; уточнять «ПО/платформа» |
| Бытовые устройства | Алиса колонка; робот игрушка; робот пылесос; говорящий робот ребенку | Исключить |
| Бесплатные инструменты | расшифровать аудио бесплатно; скачать взломанную программу; голосовой робот бесплатно без регистрации | Не цель корпоративного лендинга; не обещать бесплатный тариф |
| Шаблоны/учёба | протокол совещания образец Word; бланк протокола; реферат ИИ; диплом речевая аналитика | Не коммерческое ядро; полезный материал возможен отдельно |
| Разработка общего назначения | создать ИИ агента n8n; Python голосовой бот; скачать модель; API синтеза речи | Условно: нужны отдельные подтверждённые продукты и документация |
| Чужие бренды | Naumen цена; Just AI вход; BSS поддержка; Exolve личный кабинет | Не использовать в title/H1 своих коммерческих страниц |

«Стоимость», «интеграция», «закрытый контур», «пилот» — полезные коммерческие уточнения. «Голосовой робот» и «нейробот» сохраняются как синонимы.
