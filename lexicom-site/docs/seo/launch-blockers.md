# Lexicom — что осталось до запуска

Обновлено 6 ноября 2026 года. На GitHub опубликован `a69fccb`. Исправления финального ревью ниже подготовлены **локально**, без новой публикации и без переключения lexicom.ai.

## Требует участия специалиста и команды

1. **Рабочая отправка заявок.** Подготовлены обработчик и общая форма на 14 страницах. Получатель — **info@lexicom-ai.ru**. Специалисту нужно установить обработчик, настроить отправляющую почту, проверить получение письма в рабочем ящике и только затем включить `VITE_CONTACT_ENDPOINT` при сборке. [Инструкция передачи](../contact-form-handoff.md). Сейчас посетителю показываются прямые email и телефон. Локальные тесты не отправляют письма во внешний ящик.
2. **Перенос старого сайта.** Настроить и проверить сохранение старых страниц и архива документации, точечные постоянные перенаправления, HTTPS/www, настоящую 404, robots и sitemap. [Карта адресов](redirect-map.md). Исторические замечания к сертификату и robots относятся к проверкам 4–5 ноября; перед переключением требуется повторная проверка сервера. Проверка локальной сборки не проверяет боевой Apache. Нужны резервная копия и готовый возврат предыдущей версии.
3. **Аналитика и поисковые кабинеты.** Подключить Метрику, Яндекс Вебмастер и Google Search Console с реальными данными компании. Настроить цели: переход к контакту, отправленная заявка, email, телефон компании и линия Лексы. Сверить юридические документы с окончательным составом подключённых сервисов.
4. **Звонок Лексе.** Проверить разговор по номеру **+7 (499) 113-41-15** и передачу запроса команде. Ссылка `tel:` проверена; телефонный разговор в рамках локального ревью не выполнялся.

## Исправлено локально 6 ноября

- Повреждённый якорь URL не обрушает страницу; переход к разделу ждёт загрузки страницы.
- Кнопки продуктовых страниц фокусируют видимое поле формы, исключая антиспам-поле.
- Цена приведена к подтверждённому смыслу: **от 550 000 ₽ — минимальная стоимость всего проекта, включая внедрение**.
- Убраны пустые показатели соцзащиты; карточка передачи специалисту соответствует показанному диалогу.
- Сценарный чат заменён подборщиком продуктов по шести задачам, включая самостоятельное управление обращениями.
- Длинные вспомогательные блоки отраслевых страниц раскрываются на телефоне; на широком экране и без JavaScript содержимое доступно полностью.
- Код и стили разделены по страницам. При сборке загружается нужный модуль, затем сохраняется полный HTML; стили маршрута подключаются сразу из манифеста сборки.
- Карусель приостанавливается вне экрана и в скрытой вкладке; размеры пересчитываются при изменении геометрии.
- Обновлены Vite и source-map-js, исправлены предупреждения проверки кода.

## Проверка перед публикацией

Выполнить `npm run build:launch`, `npm run verify:launch`, `npm run lint`, `npm audit` и `npm test` в `server`. Проверить мобильное меню, подбор продукта, раскрываемые блоки, формы, видео, увеличенные изображения и переходы между страницами. Отдельно проверить на выбранном хостинге новые и сохраняемые старые URL и получение реального письма.

В сборке 18 страниц с уникальными метаданными и основным текстом в HTML, плюс отдельная 404. Телефон компании: **+7 (499) 957-81-32**. Все email-ссылки ведут на **info@lexicom-ai.ru**. Подготовка локальной версии не является публикацией на GitHub или переключением основного домена.
