# Проверка смысла запросов

12 запросов проверены отдельно; источники закреплены за каждым запросом в evidence/query-intents.json. Это расширяет предыдущее исследование с пакетными результатами, но не заменяет региональную выгрузку Яндекса/Google и не измеряет частотность. Порядок источников не трактуется как позиция.

| Запрос / группа | Что обнаружено | Решение |
|---|---|---|
| автоматизация обращений | HelpDesk, управление заявками, клиентский сервис | Главная обязана уточнять звонки/сообщения и состав платформы; не обещать универсальную СЭД |
| автоматизация клиентского сервиса | CRM/HelpDesk и экспертные материалы | /business/ — задачи обслуживания; покупку конкретного ПО переводить на продукт |
| голосовой робот для бизнеса | Коммерческие голосовые платформы и материалы выбора | /products/neurobot/; сохранить поисковый синоним |
| ИИ агент для звонков | Голосовые агенты, виртуальные операторы | Тот же продукт, не создавать страницу-дубль |
| платформа контактного центра | ПО/облачные платформы | Подходящее намерение для продукта КЦ |
| контакт центр услуги | Аутсорсинговые колл-центры | Не целевая категория без подтверждения услуги операторов |
| автоматизация МФЦ | АИС МФЦ и обработка госуслуг целиком | Уточнять автоматизацию звонков/консультаций, не заменять АИС |
| запись к врачу 122 | Сервисы для граждан | Исключить как самостоятельную коммерческую цель |
| речевая аналитика | Продукты и материалы выбора | Продуктовая страница + отдельная экспертная поддержка |
| автоматическое протоколирование совещаний | ИИ-транскрибация, корпоративные протоколы, СЭД | Уточнить входные записи, выходной документ и человеческую проверку |

| ЕКЦ 110 | Смешанные и нерелевантные расшифровки ЕКЦ | Не считать большим рынком по одному короткому названию; развивать смысл первой линии региона |

Примеры первичных источников: [HappyDesk](https://happydesk.ru/vozmozhnosti/avtomatizaciya-obraschenii-v-helpdesk), [ELMA365](https://elma365.com/ru/products/customer-service/managing-requests/), [МФЦ-Капелла](https://bft.ru/products/gosuslugi/mfts-kapella/), [приём к врачу](https://gu.spb.ru/188453/), [Tomoru для образования](https://tomoru.ru/education).

## Что означает пересмотренное ядро

semantic-core-reviewed.csv сохраняет первоначальные 268 кандидатов и добавляет статус проверки намерения, решение и доказательство. Только точное совпадение проверенного запроса помечается как отдельная проверка; остальные строки не выдаются за проверенные. Частотность остаётся пустой. Название продукта «ИИ-агент» и существующие URL сохраняются.

Не следует добивать ядро до круглой тысячи фраз. Следующий прирост качества — реальные варианты из Wordstat, удаление шума, проверка региона и целей клиента, приоритет по коммерческой ценности. Прежде чем создавать новую посадочную, нужны отдельное намерение, самостоятельное предложение и достаточная фактура.
