# Что считать готовностью, а не «идеальным SEO»

Ни один аудит не гарантирует позиции или продажи. Вместо обещания «идеально» используются проверяемые условия.

| Направление | Критерий приёмки | Сейчас |
|---|---|---|
| Техническая сборка | Все актуальные маршруты и metadata/schema, 404, нет битых внутренних целей и повторных ID | Пройдено локально для 14 страниц |
| Надёжность содержимого | Текст доступен в HTML, без JS и при ошибке его загрузки | Исправлено/проверено |
| Доступность | Автоматические проверки и ключевые действия клавиатурой; отдельный ручной аудит скринридером | Автопроверки и диалоги пройдены; полный ручной аудит не заявлен |
| Скорость | Репрезентативные страницы на реальном хостинге; полевые p75 LCP ≤2,5 с, INP ≤200 мс, CLS ≤0,1 | Главная: локальный LCP ~2,3 с; полевых данных нет |
| HTTPS/хост | Сертификаты всех вариантов домена, одна конечная версия, корректные 301/404 | WWW-сертификат требует исправления |
| Индексация | Конечный robots/sitemap, доступные canonical, проверка в кабинетах; тестовая копия noindex | Локально подготовлено; публичные версии не обновлены |
| Семантика | Измеренные запросы по РФ, намерения, карта страниц и приоритеты продаж | Кандидаты и качественное исследование есть; частотность не получена |
| Коммерческая готовность | Доставляемая заявка, достоверные контакты/условия, утверждённые документы | Форма и юридические ссылки блокируют запуск |
| Доказательства | Источники кейсов/метрик, актуальные реквизиты и карточка реестра | Нужна финальная сверка владельцами фактуры |
| Миграция | Полная карта старых URL, проверка на целевом сервере, план отката | Подготовительный план, не боевой тест |
| Измеримость | Подключены кабинеты/счётчик, различаются намерение и доставленная заявка | Не подключено |

Ориентиры полевых показателей: [Google Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals). TBT в Lighthouse не является измеренным INP посетителей. [Оценка Lighthouse меняется с условиями](https://developer.chrome.com/docs/lighthouse/performance/performance-scoring); один балл не следует превращать в гарантию.

Правило noindex: [Google — робот должен иметь доступ к странице](https://developers.google.com/search/docs/crawling-indexing/block-indexing). robots.txt по вложенному адресу Pages не управляет всем хостом: ключевой сигнал здесь находится в HTML. Конфиденциальный стенд нужно защищать доступом, а не только noindex.

Порядок: закрыть P0 → согласовать и проверить целевой сервер → настроить измерения → отдельное разрешение на публикацию → проверить публичный результат → улучшать по данным. DNS в текущем задании не меняется.
