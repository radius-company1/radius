# Проверка добавления кейса МФЦ

Дата: 04.11.2026. Первичная проверка выполнена в каноническом исходнике до публикации. Затем изменения опубликованы на GitHub Pages в коммите `8f28975`; [отчёт о релизе](../releases/2026-11-04/README.md).

## Результат

- Внутренний шаблон МФЦ удалён из компонента и данных.
- Добавлен подробный кейс Кузбасса: контракт с 2025 года, 1 234 документа, задача, работа RAG, три направления адаптации, ценность для сотрудника и награда проекта.
- На главной добавлена отдельная карточка над прежними тремя кейсами. Заголовок раздела отражает подборку региональных проектов, включая внедрение Кузбасса, а не приписывает всем один статус.
- Разбор поднят ближе к началу страницы МФЦ; на первом экране есть ссылка. В показателях МФЦ общее «до 90%» заменено на 1 234 документа с указанием конкретного проекта.
- Ссылки на кейс добавлены в подборку ИИ-агента и раздел помощи оператору контактного центра.
- Прежний кейс МФЦ Новосибирской области восстановлен отдельным блоком.
- Телефон Лексы +7 (499) 113-41-15 сохранён.

## Проверки

- `npm run build:launch` — успешно.
- `npm run verify:launch` — успешно: 17 страниц, 16 перенаправлений к URL с `/`, 17 перенаправлений с `index.html`, три настоящих 404, метаданные и карта сайта. В текущем исходнике уже есть три юридические страницы; они не создавались в этой задаче.
- `oxlint src` — успешно.
- 12 открытий четырёх затронутых страниц на 390, 768 и 1440 px — 200, один H1, без горизонтального переполнения и ошибок JavaScript.
- Переходы с главной, ИИ-агента и контактного центра открывают `/mfc/#mfc-experience`.
- Раскрытие технических подробностей работает клавиатурой.
- Проверка axe новых блоков на четырёх страницах — без нарушений WCAG A/AA. Существующие части сайта этим результатом не переоценивались.
- Отдельная проверка с выключенным JavaScript: кейс и Новосибирск видимы, скрипты не запрашиваются, технические подробности содержатся в HTML, новый показатель 1 234 присутствует.
- Просмотрены скриншоты главной и разбор МФЦ на телефоне/компьютере, схема работы на телефоне.

## Изменённые исходники

1. `src/data/mfcCases.ts` — единая фактура двух кейсов МФЦ.
2. `src/components/MfcCaseFeature.tsx` — карточка Кузбасса для главной.
3. `src/components/mfc/MfcExperience.tsx` — полный кейс вместо шаблона.
4. `src/components/Cases.tsx` — новый акцент в подборке проектов.
5. `src/pages/MfcPage.tsx` — порядок секций.
6. `src/components/mfc/MfcHero.tsx` — ссылка с первого экрана.
7. `src/components/CustomerCase.tsx` — контекстная ссылка в подборке ИИ-агента.
8. `src/components/contact-center/CcPrompter.tsx` — ссылка из раздела помощи сотруднику.
9. `src/data/directions/mfc.ts` — удаление пустого шаблона, новый показатель и описание для поиска.
10. `src/styles/mfc-case.css` — оформление и адаптация новых блоков.
