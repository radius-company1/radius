# Выпуск GitHub Pages — 7 ноября 2026

Пакет обновления предварительного сайта `https://radius-company1.github.io/radius/lexicom/`. Основной домен `lexicom.ai` и DNS не переключаются. Предыдущая версия — `a69fccb`.

## Что входит

- Быстрое однократное появление экранов пяти продуктов на главной и связанных экранов на продуктовых страницах. Диалог раскрывается за 3,3 секунды, остальные сценарии — за 2–2,5 секунды. После завершения всё остаётся видимым. Нет паузы, повтора и внутренней прокрутки; увеличение изображения сохранено.
- Все доработки [финального ревью 6 ноября](../local-polish-2026-11-06.md): загрузка кода и стилей по маршрутам, полная предварительная HTML-разметка, компактные вспомогательные блоки на телефоне, подбор продукта по задачам, исправления навигации, фокуса формы и фактических формулировок.
- Обновлённые зависимости и устранение предупреждений проверки кода. Анимация карусели останавливается за экраном.

## Проверка перед выпуском

Сборка для основного домена и проверка 18 маршрутов пройдены; код проверен без предупреждений. Быстрое появление пяти карточек, постоянная высота и отсутствие повторов проверены в браузере. Шесть затронутых маршрутов проверены при 320, 390 и 1440 px, с уменьшением движения и без JavaScript.

Отдельная сборка публикации выполняется через `scripts/deploy-lexicom.sh`. В ней используется префикс `/radius/lexicom/`, страницы отмечены `noindex`. Подтверждение публичных HTML и ресурсов сохраняется после push в `artifacts/lexicom-release-2026-11-07/` рабочего проекта.

Рабочая доставка заявок и перенос основного домена остаются отдельными шагами: [блокеры запуска](../seo/launch-blockers.md), [инструкция специалисту по формам](../contact-form-handoff.md).
