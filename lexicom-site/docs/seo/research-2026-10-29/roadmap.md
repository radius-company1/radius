# План развития и измерений

Приоритет основан на соответствии продукту и готовности контента, не на неизвестной частотности. Этапы не являются обещанием срока получения позиций.

## 1. Проверка спроса

В Wordstat измерить фразы: Россия, фиксированный период/устройство, отдельно широкое и уточнённое значение. Сохранить использованные операторы. Не суммировать вложенные широкие частоты — они пересекаются. «В кавычках» и фиксация словоформ — разные измерения. [Справка операторов](https://yandex.ru/support2/wordstat/ru/content/operators).

Search Console/Вебмастер: запросы, страницы, показы, клики, позиции за сопоставимые периоды, отдельно бренд/небренд. CRM: продукты и отрасли с квалифицированными обращениями, вопросы покупателей и причины отказа. Узкий B2G-запрос может быть ценным при небольшой частоте.

После выгрузок: отсев шума, реальные варианты фраз, проверка выдачи основных запросов с фиксированными поисковиком/регионом/датой. Кластеризовать по намерению и пересечению результатов, не только словам. Отсутствие частоты в одном замере не доказывает отсутствие потребности.

## 2. Запуск

Закрыть юридические документы, доставку форм, подтверждение рекламных утверждений. Согласовать 301 и сохранение старых страниц, проверить реальный HTTP 404. В конечной launch-сборке нет noindex; тестовый Pages не индексируется. robots/noindex не защищают приватные материалы.

## 3. Существующие страницы

P1: главная, ИИ-агент, контактный центр, аналитика, бизнес, ресурсоснабжение. Добавить подтверждённые примеры, FAQ по расчёту/интеграциям, кейсы и контекстные связи.

P2: отраслевые B2G/образование, ЕКЦ, специализированные сценарии протокола. Приоритет пересмотреть по данным продаж. У каждой отрасли свои данные, процессы, ограничения, критерии результата.

## Контроль результата

События: выбор продукта/отрасли, запрос демо, клик по телефону/email, отправка формы и отдельно подтверждённая доставка. Клик по кнопке не равен заявке. Не отправлять содержание заявки в аналитику без согласованного основания.

Основной показатель — квалифицированные органические обращения по продукту/отрасли. Диагностика: индексируемые canonical, небрендовые показы/клики, CTR при сопоставимых позициях, ошибки 404, страницы входа, конверсия в доставленную заявку. Отдельно бренд и старые перенаправленные URL. Учитывать сезонность приёмной кампании и закупок.

Сразу после запуска проверить HTTP и индексационные настройки; еженедельно — ошибки/заявки; ежемесячно — кластеры и качество лидов. Числовые цели задавать после базового измерения. Рост трафика, позиции и лиды сейчас не обещаются.

Ссылки: собственные публичные кейсы, корректные карточки реестра, партнёрские профили. Не массовая закупка ссылок. Аудит ссылочного профиля не выполнен: выгрузки индекса нет.
